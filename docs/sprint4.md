# Sprint 4 – Entrega Final

## Descripción
En este sprint se completó el desarrollo de la app DripDesk, integrando el frontend, un backend propio y persistencia local.

---

## Funcionalidades

- Login con Firebase
- Crear prendas
- Envío de datos a un backend propio (API)
- Guardado local con SQLite
- Notificaciones al guardar prendas
- Visualización de prendas en el home

---

## Backend

Se creó una API con Node.js y Express.

Endpoints:
- POST /garments
- GET /garments/:userId

Se validó viendo en la terminal que llegan las solicitudes desde la app.

---

## Persistencia

- Firebase → autenticación
- SQLite → almacenamiento local de prendas
